Project Ⅰ

Splearn
Clean Architecture · DDD

Splearn — 온라인 강의 플랫폼

회원, 강사, 강의, 수강, 커리큘럼 다섯 개 도메인을 가진 강의 플랫폼입니다. 도메인 모델 패턴과 헥사고날 아키텍처를 적용해, 비즈니스 규칙이 프레임워크와 인프라에 의존하지 않도록 설계했습니다.

역할개인 프로젝트 · 설계와 개발 전체
도메인회원 · 강사 · 강의 · 수강 · 커리큘럼
테스트도메인 · 서비스 · API · 아키텍처
splearn
├─ domain          애그리거트, 값 객체, 도메인 규칙
├─ application
│   ├─ provided    인바운드 포트 (MemberRegister, CourseFinder …)
│   ├─ required    아웃바운드 포트 (MemberRepository, EmailSender …)
│   └─ service     애플리케이션 컴포넌트
└─ adapter
    ├─ webapi      REST API, ProblemDetail 예외 처리
    ├─ persistence JPA 매핑 (도메인과 분리)
    └─ security    회원 인증 어댑터
회원 인증 포트

비밀번호 해싱과 인증을 아웃바운드 포트로 분리해 도메인이 보안 구현을 모르게 했습니다.

ArchUnit 의존 규칙 검증

계층과 애플리케이션 컴포넌트 간 의존 방향을 테스트로 고정해 구조가 무너지지 않게 했습니다.

JPA 매핑 분리

엔티티 클래스에서 매핑 정보를 떼어내 도메인 코드를 순수하게 유지했습니다.

테스트 픽스처 개선

Instancio로 랜덤 데이터를 생성해 테스트가 특정 값에 기대지 않도록 했습니다.

TROUBLE SHOOTING

커리큘럼과 강의 컴포넌트가 서로를 참조하는 양방향 의존이 생겼습니다. 커리큘럼 쪽에 필요한 기능만 담은 포트를 정의하고 강의 컴포넌트가 이를 구현하도록 의존을 역전(DIP)해 순환을 끊었고, ArchUnit 슬라이스 테스트로 재발을 막았습니다.

Project Ⅱ

E-commerce MSA
Microservices · Event Driven

E-commerce 마이크로서비스

사용자, 상품, 주문 서비스를 분리한 쇼핑몰 백엔드입니다. API Gateway에서 JWT 인증을 처리하고, 서비스 간 데이터는 Kafka로 동기화합니다.

역할개인 프로젝트 · 설계와 개발 전체
서비스User · Catalog · Order + 인프라 4종
배포Docker · Kubernetes
Client
  └─ API Gateway ── AuthorizationHeaderFilter (JWT 검증)
       ├─ User Service     Spring Security, BCrypt, JWT 발급
       ├─ Catalog Service  ◀── Kafka ── 재고 차감 이벤트
       └─ Order Service    ── Kafka Producer ──▶ Sink Connect ─▶ DB
Discovery: Eureka · Config: Spring Cloud Config + Bus(RabbitMQ)
Tracing: Zipkin · Metrics: Micrometer → Prometheus → Grafana
Gateway 인증 필터

로그인 시 JWT를 발급하고, Gateway 필터에서 토큰을 검증해 각 서비스가 인증 로직을 중복 구현하지 않게 했습니다.

설정 중앙화와 암호화

Config 서버로 설정을 모으고 비대칭키로 민감 값을 암호화했으며, Bus로 무중단 갱신했습니다.

장애 전파 차단

Resilience4J CircuitBreaker로 주문 조회 실패가 사용자 서비스 전체 장애로 번지지 않게 했습니다.

분산 추적

Zipkin으로 요청 하나가 여러 서비스를 거치는 경로와 지연 구간을 추적했습니다.

TROUBLE SHOOTING

주문 서비스를 여러 인스턴스로 늘리자 각 인스턴스의 DB에 주문이 흩어지는 동기화 문제가 생겼습니다. 주문 이벤트를 Kafka 토픽으로 발행하고 Sink Connector가 단일 DB에 적재하도록 바꿔 인스턴스 수와 무관하게 데이터 일관성을 확보했습니다.
