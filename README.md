## 배포

정적 HTML 한 장(`index.html`)으로 구성되어 있으며 GitHub Pages로 배포합니다.

1. Repository → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / `(root)` 선택 후 Save
